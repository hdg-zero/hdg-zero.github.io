## Choosing Simplicity

When I evaluated my requirements for a personal developer portfolio, I settled on a clear checklist:
- Simple to use,
- Easy to update,
- Quick to set up,
- Cost-effective (free hosting),
- And visually polished.

GitHub Pages immediately stood out due to its established track record, seamless Git integration, and native support across developer workflows. It checked every box: simplicity, zero hosting costs, and swift deployments.

The second decision was the underlying web framework. I explored modern web architectures, evaluated various static site generators, and discovered Astro. Astro is exceptionally fast, delivers zero JavaScript by default, is open-source, and has great ecosystem support. Those qualities made it an ideal choice.

## Tooling & Initial Setup

Before writing any complex UI code, I set up a barebones GitHub repository to perform a dry run of the deployment pipeline with a simple static file:

### Setup Steps
0. Ensure an active GitHub account.
1. Create a repository named `x.github.io` (where `x` is your username).
2. Add a basic `README.md` or static `index.html`.
3. Configure GitHub Pages deployment via GitHub Actions.
4. Verify proper deployment at `https://x.github.io`.

Once this foundational pipeline was validated, I proceeded to create the Astro project following the [Astro Manual Setup](https://docs.astro.build/en/install-and-setup/#manual-setup).

## Building the Site

With basic scaffolding verified locally, I customized the visual design, crafting a liquid glassmorphic theme with modern CSS gradients, responsive Bento grids, and smooth client transitions.
